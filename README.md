Почта России

Клиент-серверное консольное приложение на языке Python, моделирующее работу почтовой службы «Почта России». Программа управляет отделениями почты и движением посылок между ними, позволяет отслеживать статус доставки, моделировать течение времени и сохранять данные между запусками.

Архитектура

Приложение построено по клиент-серверной модели. Сервер хранит данные об отделениях и посылках, обрабатывает бизнес-логику — расчёт маршрутов, времени доставки, выдачу посылок — и ведёт учёт состояния. Клиент представляет собой консольный интерфейс пользователя: он отправляет запросы на сервер и получает ответы. Взаимодействие происходит по схеме «запрос — ответ»: клиент формирует запрос (например, «показать отделение», «найти посылку», «прокрутить время»), сервер обрабатывает его и возвращает результат. Такая архитектура разделяет интерфейс и логику, упрощает масштабирование и позволяет нескольким клиентам работать с одним сервером.

Основные сущности

Посылка

Содержит:

· Трек-номер — уникальный идентификатор посылки
· Отправитель — ФИО отправителя
· Получатель — ФИО получателя
· Вес — масса посылки
· ID отделения отправления — откуда посылка была отправлена
· ID отделения назначения — куда посылка должна прибыть

Отделение

Содержит:

· Уникальный ID — идентификатор отделения
· Название — название отделения почты
· Координаты (X, Y) — положение на плоскости
· Список посылок — посылки, находящиеся внутри отделения

Функционал

1. Добавление и удаление отделений почты

· Добавление новых отделений с указанием названия и координат
· Удаление существующих отделений
· При удалении отделения все посылки, которые находятся в нём или направляются в него, автоматически возвращаются отправителю

2. Просмотр информации об отделении

· Список посылок, лежащих внутри отделения
· Список посылок, которые уже отправлены и находятся в пути в данное отделение, с указанием оставшегося времени в днях
· Координаты отделения на плоскости

3. Поиск посылки по трек-номеру

Отображается:

· Откуда отправлена
· Куда следует
· Текущее местоположение
· Сколько дней осталось до прибытия (если посылка в пути)

4. Выдача посылки получателю

· Выдача посылки с обязательной проверкой ФИО получателя
· Посылка выдаётся только при совпадении введённых данных с данными в системе

5. Моделирование времени

· Задаётся скорость доставки (км/день)
· Расстояние между отделениями вычисляется по формуле (по координатам X, Y)
· Время в пути = расстояние / скорость, с округлением вверх до целых дней
· При «прокрутке» времени на N дней все посылки, находящиеся в пути, приближаются к пункту назначения
· Прибывшие посылки автоматически помещаются в целевое отделение

6. Сохранение и загрузка данных

· Все отделения и посылки сохраняются в текстовые файлы
· При запуске данные загружаются обратно, что позволяет продолжать работу между сессиями

Технологии

· Язык: Python
· Архитектура: клиент-серверная, схема «запрос — ответ»
· Интерфейс: консольный (клиент)
· Хранение данных: текстовые файлы (на стороне сервера)
· Библиотеки: стандартная библиотека Python (socket, threading, math, json)
